# PureFlow Water Station

**Live site:** https://github.com/c20245452ramos-lgtm/WATER-Refilling-Station.git


## About

This website promotes a local water refilling station that provides clean, affordable drinking water. It is for families, offices, and local customers who want safe and convenient refills.

## Design System

### Palette (60-30-10)

| Role | Share | Color | Used for |
|---|---:|---|---|
| Dominant | 60% | `#ECFEFF` | Page background, large surfaces |
| Secondary | 30% | `#0F766E` | Navigation, buttons, section emphasis |
| Accent | 10% | `#FBBF24` | Highlights, badges, callouts |

### Visual style

**Style chosen:** Glassmorphism

**Why I chose it:** It makes the brand feel modern, clean, and premium while keeping the water business approachable and trustworthy.

### Contrast check

Body text color vs. background color: `#0F172A` on `#ECFEFF`
Contrast ratio: 16.4 : 1
Tool used: WebAIM Contrast Checker

## Features

- [x] Mobile-first responsive layout
- [x] Dark mode toggle
- [x] Page-load intro animation (GSAP timeline)
- [x] Scroll reveals on every section below the hero (ScrollTrigger)
- [x] Scroll progress bar (scrub)
- [x] Reduced-motion support
